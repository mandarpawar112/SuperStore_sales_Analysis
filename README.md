# SuperStore_sales_Analysis

# 🛒 Retail Sales Analysis | Python, MySQL & Power BI

## 📌 Project Overview
The **Retail Sales Analysis Project** is an end-to-end data analytics project focused on analyzing retail sales data to identify business trends, evaluate profitability, and generate meaningful insights.

The project uses Python for data exploration and preprocessing, MySQL for data querying and analysis, and Power BI to build an interactive dashboard for visualizing key business performance indicators.

## 🎯 Project Objectives
- Analyze overall sales, profit, and quantity performance.
- Identify top-performing products and categories.
- Understand sales and profit trends over time.
- Analyze regional and customer segment performance.
- Identify products and categories generating losses.
- Build an interactive dashboard to support data-driven decisions.

## 📂 Project Workflow

### 1. Data Analysis & Preprocessing – Python
- Imported and explored the Superstore dataset.
- Checked data types, missing values, and duplicate records.
- Converted date columns into appropriate date formats.
- Validated numerical and categorical columns.
- Created additional columns for analysis.
- Performed Exploratory Data Analysis (EDA).
- Generated visualizations to identify sales and profit trends.

### 2. Data Analysis – MySQL
- Imported the prepared dataset into MySQL.
- Used SQL queries to analyze business performance.
- Calculated total sales, profit, and quantity.
- Identified top 10 products and customers.
- Analyzed sales by category, region, and segment.
- Evaluated monthly and yearly sales trends.
- Investigated loss-making products and discount impact.

### 3. Dashboard Development – Power BI
- Connected the prepared dataset to Power BI.
- Created KPI cards for key business metrics.
- Developed charts for category, regional, and product analysis.
- Created sales and profit trend visualizations.
- Added interactive slicers and filters.
- Designed an interactive dashboard for business insights.

## 📈 Dashboard Features
- **Sales Performance:** Track total sales and profit.
- **Category Analysis:** Compare sales across product categories.
- **Product Analysis:** Identify top 10 products by sales.
- **Regional Analysis:** Compare performance across regions.
- **Customer Analysis:** Identify high-value customers.
- **Time Analysis:** Explore monthly and yearly sales trends.
- **Profitability Analysis:** Understand profit margins and loss-making products.
- **Interactive Filtering:** Filter the dashboard by date, region, category, segment, and ship mode.
